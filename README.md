# curveengine

Multi-curve fixed-income term structure construction, pricing and interest-rate risk.

## Installation

```bash
pip install -e .
```

## Development

Install development dependencies:

```bash
pip install -e ".[dev]"
```

Run tests:

```bash
pytest
```

Run code quality checks:

```bash
ruff check .
ruff format --check .
mypy
```
